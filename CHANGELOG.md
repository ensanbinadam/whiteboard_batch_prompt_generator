# Changelog

## 2.5 — Stability release based on the proven 2.3 engine
- Byte-for-byte preservation of v2.3 prompt-construction engine, in Arabic and English, across batch and single-asset modes.
- New groups default to full-color soft pastel PNG, transparent background and 2048 × 2048 target, matching the successful fruit test settings.
- A one-click “tested fruit quality” preset applies these settings without erasing assets, context or notes.
- Warning for >5 assets, and explicit warning when more than 60 lines would otherwise be silently ignored.
- Keep 2.3 local group storage and fall back to 2.4 or 2.2 groups when 2.3 groups do not exist.
- No file organizer, scene numbering, forced filenames or changes to the image-generation prompt engine.


## 2.3 — Simplified teaching workflow
- Removed scene numbers and compulsory image filenames from the interface and prompts.
- Removed output image organizer, ZIP-rename workflow, and JSON export controls.
- Retained strict separate-asset batch requests and the optional single-item prompt.
- Kept PNG/SVG/WebP/color/style controls, with optional advanced options in a collapsed section.
- Kept only optional local saved group names and lists; migration from v2.2 is attempted without deleting old data.
- Preserved educator credit footer and documented actual limitations.
