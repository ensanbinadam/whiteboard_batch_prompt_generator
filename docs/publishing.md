# نشر مولّد عناصر السبورة التعليمية على GitHub Pages

هذا الدليل موجّه لمن لا يحتاج إلى البرمجة أو سطر الأوامر.

## قبل البدء

- امتلك حسابًا على [GitHub](https://github.com).
- فكّ ضغط حزمة المشروع على جهازك.
- تأكد من وجود ملفي **`index.html`** و**`generator.html`** في جذر المجلد.

## النشر خطوة بخطوة

1. من GitHub اختر **New repository**، وسمّه `whiteboard-batch-prompt-generator` أو اسمًا تختاره.
2. اختر **Public** ليتمكن الجميع من زيارة الموقع مجانًا، ثم اضغط **Create repository**.
3. داخل المستودع اضغط **Add file → Upload files**، وارفع **محتويات المجلد بعد فك الضغط**، وليس ملف ZIP نفسه. حافظ على مجلدي `assets` و`docs` كما هما.
4. أكد رفع الملفات برسالة Commit مثل `Initial public release`.
5. افتح **Settings → Pages**.
6. تحت **Build and deployment** اختر **Source: Deploy from a branch**.
7. حدد الفرع **`main`**، والمجلد **`/(root)`**، ثم **Save**.
8. انتظر انتهاء النشر، ثم افتح الرابط الظاهر في صفحة **Pages**.

في العادة، إذا كان اسم المستخدم `USERNAME` واسم المستودع `whiteboard-batch-prompt-generator`، يكون رابط المشروع على نمط:

```text
https://USERNAME.github.io/whiteboard-batch-prompt-generator/
```

استبدل `USERNAME` باسم حسابك الفعلي. الرابط أعلاه **مثال وليس رابطًا منشورًا بالفعل**.

## اختبار النشر

بعد فتح الموقع:

- [ ] تظهر صفحة تعريف المشروع `index.html`.
- [ ] يعمل زر **«افتح المولّد الآن»** ويعرض `generator.html`.
- [ ] يعمل زر **«مثال 4.2 الناجح»**.
- [ ] تتغير تعليمات البرومبت بتغيير نمط الألوان.
- [ ] يعمل تبويب **«برومبت عنصر مستقل»**.
- [ ] تعمل أزرار النسخ وحفظ JSON بحسب صلاحيات المتصفح.
- [ ] تظهر صور الفواكه والأيقونة على الصفحة الرئيسية.

## أخطاء شائعة

**الصفحة تعرض 404:** تأكد من وجود `index.html` في جذر المستودع، وليس داخل مجلد إضافي. راجع Settings → Pages والفرع والمسار.

**الرابط للبرنامج لا يعمل:** تأكد من وجود `generator.html` في نفس مستوى `index.html`.

**صور الأمثلة لا تظهر:** تأكد من رفع مجلد `assets` مع الحفاظ على أسماء الملفات.

**التعديل لا يظهر:** انتظر قليلًا وحدّث الصفحة تحديثًا كاملًا، ثم راجع آخر عملية نشر في GitHub Actions.

**تظهر رسالة عند نسخ البرومبت محليًا:** جرّب Chrome/Edge واستخدم النسخ اليدوي عند الحاجة. على GitHub Pages يعمل الموقع عبر HTTPS، ما يساعد صلاحيات الحافظة الحديثة.

## نشر تحديث لاحق

غيّر الملفات على جهازك، ثم افتح المستودع واختر **Add file → Upload files** أو استخدم Git، واحفظ التعديل. GitHub Pages سيعيد نشر الموقع بعد اكتمال التحديث.
