# 🎨 مولّد عناصر السبورة التعليمية

**Whiteboard Batch Prompt Generator Pro** — أداة مجانية ومفتوحة المصدر تساعد المعلمين والمعلمات على إنشاء **برومبت جماعي صارم** لطلب رسومات تعليمية منفصلة من أدوات توليد الصور بالذكاء الاصطناعي.

> **شعار المشروع:** من فكرة الدرس إلى عناصر تعليمية جاهزة.

[**ملف المولّد المستقل**](generator.html) · [**صفحة التعريف**](index.html) · [**دليل المعلم**](docs/teacher-guide.md) · [**دليل النشر**](docs/publishing.md)

## لمن هذه الأداة؟

للمعلمين والمعلمات، ومعلّمي رياض الأطفال، وصناع المحتوى التعليمي، وكل من يريد صورًا منفصلة لبناء دروس وبطاقات وأنشطة وعروض PowerPoint.

## ماذا تفعل؟

1. تكتب أسماء العناصر التي تحتاجها، **عنصرًا في كل سطر**: تفاحة، برتقالة، موزة، كمثرى، عنب.
2. تختار أسلوب Whiteboard، والألوان، والهيئة، والملامح، والخلفية، والدقة.
3. يولّد البرنامج برومبتًا جماعيًا يطلب **عددًا محددًا من الصور المنفصلة** مع أسماء ملفات مرقمة وتعليمات جودة واضحة.
4. تنسخ البرومبت إلى أداة ذكاء اصطناعي تدعم توليد الصور، ثم تستخدم النتائج في PowerPoint أو نشاطك التعليمي.

**تنبيه مهم:** المولّد **لا ينشئ الصور بنفسه** ولا يتصل بخدمة توليد صور. إنجاز ZIP أو SVG أو الحفاظ على الشفافية الحقيقية يعتمد على الأداة الخارجية المستخدمة. بعض الأدوات لا تستطيع إخراج ملفات متعددة في طلب واحد؛ عندها يمكن استخدام برومبت مستقل لكل عنصر.

## المزايا

- برومبت جماعي صارم مبني على قالب **Whiteboard Studio 4.2** الذي نجح في اختبارات المستخدم.
- أسماء عناصر عربية حرفية دون استبدال داخل البرومبت.
- ملفات مقترحة مرقمة ومطابقة للقائمة، وخيار طلب ZIP.
- اختيار صيغة واقعي: PNG، وSVG متجهي إلزامي، وSVG مفضّل مع PNG بديل بامتداد صحيح، وWebP.
- برومبت فردي لكل عنصر عند الحاجة.
- أربعة أوضاع للألوان: أبيض وأسود، إبراز بلون واحد، ألوان هادئة، ألوان مبهجة.
- قوالب جاهزة للتعليم والسبورة الكلاسيكية والشخصيات والبطاقات.
- إعدادات التعبير والعينين والزاوية والوضعية والوجوه الكرتونية واتساق الرسم.
- إنشاء مجموعات متعددة محفوظة في المتصفح والتبديل بينها، مع نسخة احتياطية JSON لجميع المجموعات.
- منظّم صور حقيقي: تعيين كل ملف ناتج إلى عنصره يدويًا ثم تنزيل PNG/SVG/WebP/JPEG بالاسم المرجعي الصحيح، منفردًا أو في ZIP فعلي.
- استيراد وتصدير إعدادات مجموعة واحدة بصيغة JSON وتصدير ملفات TXT.
- واجهة عربية واتجاه كتابة RTL، وتعمل محليًا دون تثبيت أو خدمات خلفية أو مكتبات خارجية.

## تشغيل البرنامج

يمكنك تشغيله بطريقتين:

- **محليًا:** نزّل ملف [`generator.html`](generator.html) وافتحه في متصفح حديث مثل Chrome أو Edge.
- **عبر GitHub Pages:** انشر محتويات هذا المستودع. ستكون صفحة التعريف في `index.html` وأداة المولّد في `generator.html`.

## مثال تعليمي

اكتب في «جميع العناصر»:

```text
تفاحة
برتقالة
موزة
كمثرى
عنب
```

اختر **«تعليمي ملوّن للأطفال»**، وخلفية **شفافة**، وصيغة **PNG**، وطريقة تسليم **ZIP**، ثم انسخ البرومبت الجماعي. تستطيع أيضًا فتح [إعدادات المثال](examples/fruits-settings.json) من زر «فتح إعدادات JSON» داخل المولّد.

## اختيار صيغة الإخراج بواقعية

- **PNG عالي الجودة**: الأفضل عادةً للصور الملونة مع خلفية شفافة، ولإدراجها وتحريكها في PowerPoint. ليست مسارات قلم.
- **SVG مفضّل — بديل PNG عند التعذر**: يطلب SVG قابلًا للتحرير أولًا، ويسمح بملف `.png` صحيح عند عدم دعم المتجهات. يذكر البرومبت **اسمي الملفين المحتملين** ويطلب تسليم **ملف واحد فقط لكل عنصر**.
- **SVG متجهي حقيقي فقط**: لا يقبل PNG بديلًا؛ يشترط مسارات متجهية مثل `<path>` ولا يقبل مجرد صورة نقطية مضمّنة في غلاف SVG. عند عدم الدعم يجب أن تصرّح أداة التوليد بالعجز.
- **WebP**: خيار صورة نقطية أخرى، وليست SVG.

**التحقق مهم:** الخيارات السابقة توجه أداة توليد خارجية، ولا يفحص المولّد تلقائيًا ملفات تلك الأداة. افحص الصيغة الحقيقية: فتح SVG كمستند نصّي يجب أن يظهر أشكالًا أو مسارات متجهية حقيقية، وليس عنصر `<image>` يتضمن PNG/JPEG فقط. لا يكفي تغيير اسم `.png` إلى `.svg`.

## الخصوصية والحدود

الأداة تعمل داخل المتصفح، ولا ترسل قائمة العناصر إلى خادم، ولا تحتوي على تحليلات أو تتبع، وتستخدم **التخزين المحلي** لحفظ آخر إعداداتك في المتصفح. عند نسخ البرومبت إلى خدمة خارجية، تخضع البيانات لشروط خصوصية تلك الخدمة. لا تُدخل بيانات طلاب شخصية أو حساسة في أدوات توليد عامة دون إذن مناسب.

المولّد ينشئ **تعليمات نصية فقط**؛ ولا يمكن أن يضمن وفاء أداة الصور بأسماء الملفات، أو عددها، أو اتساقها، أو إخراج SVG متجهي حقيقي.

## جديد في 2.2 — ما الفرق بين البرومبت والملفات الفعلية؟

- **اسم المجموعة:** يحفظ اسم مجموعة مستقلة محليًا مع عناصرها وإعداداتها، ويمكن إنشاء مجموعات أخرى والتبديل بينها.
- **رقم المجموعة:** يستخدم في بادئة الملفات `scene_XX_asset_YY` التاريخية المتوافقة مع القالب الناجح؛ **لا ينشئ مشهدًا متحركًا**.
- **حفظ كل المجموعات JSON:** ينشئ ملف نسخة احتياطية للمكتبة، لا ملف صور ولا مشاهد PowerPoint.
- **أسماء الملفات في البرومبت:** تعليمات لأداة خارجية، وليست إعادة تسمية مضمونة.
- **منظّم ملفات الصور:** بعد تنزيل الصور، أرفق كل صورة بالعنصر الصحيح بنفسك ثم نزّلها بالاسم `scene_XX_asset_YY.<actual_format>` أو ضمن ZIP حقيقي. لا تغيّر الأداة صيغة الصورة ولا محتواها.
- **التخزين:** المجموعات تحفظ في `localStorage` داخل المتصفح/الأصل الحالي، وقد تزول عند تنظيف بيانات المتصفح أو تغيير الجهاز؛ صدّر المكتبة إلى JSON. الصور المرفقة غير محفوظة بعد التحديث.
- **محدودية الصيغ:** تعيين صور SVG لا يضمن أنها متجهية حقيقية أو خالية من صورة نقطية مضمّنة، والشفافية لا تُضمن بمجرد امتداد PNG.
