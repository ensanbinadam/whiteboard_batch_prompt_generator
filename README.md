# مولّد عناصر السبورة التعليمية — النسخة المستقرة 2.4.1

**أداة مجانية ومفتوحة المصدر للمعلمين والمعلمات.** اكتب أسماء العناصر المطلوبة بالعربية، واختر أسلوب الرسم، ثم انسخ برومبتًا يطلب من أداة توليد صور خارجية إنشاء كل عنصر **في صورة منفصلة**.

[فتح المولّد](generator.html) · [الصفحة الرئيسية](index.html) · [دليل المعلمين](guide.html) · [النشر على GitHub Pages](publish.html)

## الوظيفة الأساسية

1. أدخل أسماء العناصر، عنصرًا واحدًا لكل سطر.
2. اختر نمط التلوين والخلفية والصيغة (PNG أو SVG أو WebP)، وعدّل التفاصيل الإضافية إن احتجت.
3. انسخ البرومبت الجماعي أو برومبت العنصر الفردي عند الحاجة.
4. أنشئ الصور عبر أداة الذكاء الاصطناعي التي تفضلها، ثم أدرج النتائج يدويًا في PowerPoint أو أي برنامج آخر.

**لا يطلب المولّد أسماء ملفات محددة أو أرقام مشاهد أو ZIP.** أداة الصور قد تُسمي الملفات تلقائيًا؛ هذا طبيعي ولا يؤثر في فصل الصور. لا يحتوي المولّد على منظّم صور أو محرّر مشاهد، ولا ينشئ الصور بنفسه.

## تنظيم المجموعات (اختياري)

قسم «مجموعاتي المحفوظة» مطوي افتراضيًا. يمكنك إنشاء أسماء مجموعات، وحفظ قائمة العناصر وإعداداتها داخل المتصفح الحالي. اسم المجموعة **ليس جزءًا من البرومبت**. لا تُرسل البيانات إلى خادم، وقد تضيع المجموعات المحلية عند مسح بيانات المتصفح.

عند أول فتح للإصدار 2.4.1 في المتصفح نفسه، يحاول المولّد نقل مجموعات الإصدار 2.2 إن كانت محفوظة؛ لا يحذف بيانات الإصدار القديم ولا يغيّر موقعه تلقائيًا.

## اختيارات الصيغة

- PNG: صورة نقطية عالية الجودة، غالبًا مناسبة لـ PowerPoint.
- SVG إن توفر، وإلا PNG: تفضيل مرن؛ تعذر SVG حقيقي لا يعني فشل البرومبت.
- SVG حقيقي فقط: يتطلب أداة تدعم إنتاج مسارات متجهية فعلية؛ لا يكفي ملف PNG غُلّف في SVG.
- WebP: صورة نقطية أخرى.

الشفافية وتسمية الملفات وجودة الصور تعتمد على أداة التوليد الخارجية. البرومبت يطلب ولا يضمن التنفيذ.

## النشر

موقع ثابت يعمل محليًا أو عبر GitHub Pages. افتح [دليل النشر](publish.html) أو [ملف الدليل](docs/publishing.md). يتم تشغيل المشروع من `index.html` وتتوفر الأداة في `generator.html`، بلا خدمات خلفية أو أدوات بناء.

**النسخة المستقرة 2.4.1** يقلل الخطوات ويزيل منظّم الملفات ومتطلبات التسمية وأرقام المشاهد. للمساهمة والمراجعة، راجع [CONTRIBUTING.md](CONTRIBUTING.md).

الشفرة والوثائق الأصلية برخصة **MIT**، مع مراعاة شروط استعمال صور الأمثلة الناتجة من أدوات الذكاء الاصطناعي.
