# صور الأمثلة

صور الفواكه المصغرة هنا مأخوذة من أمثلة نجاح تجريبية شاركها مستخدم المشروع، وتظهر فقط لإيضاح شكل النتائج الممكنة. وهي ليست رسومات مُنشأة بواسطة ملفات الموقع نفسها.

رخصة MIT في جذر المستودع تخص الشيفرة والوثائق الأصلية للمشروع. يجب على من يريد إعادة استخدام الصور مستقلة مراجعة شروط خدمة مولد الصور الذي أنتجها وحقوق استخدامها.
